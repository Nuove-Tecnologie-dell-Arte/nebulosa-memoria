# Nebulosa

Una memoria collettiva di foto dell'Accademia di Belle Arti di Napoli. Ogni foto viene letta per quello che rappresenta e diventa una sfera di luce in una nebulosa 3D, senza nomi né categorie. Chi inquadra il QR può aggiungere le proprie foto.

Per accenderla: doppio clic su `Apri la nebulosa.command` (Mac) o `Apri la nebulosa.bat` (Windows), oppure `bash avvia-server.sh` (Linux/WSL); tutti passano da `avvia.py`. Le impostazioni (porta 8002, indirizzo del tunnel, cartella dei dati) sono in `.env`: copia `.env.example`. Per tenerla sempre accesa in WSL: `bash servizio/installa.sh`. Servono Python 3 e Chrome; le librerie sono in `requirements.txt`. La guida completa è in `LEGGIMI.html`.

Nelle foto pubblicate qui la posizione GPS è stata tolta.
